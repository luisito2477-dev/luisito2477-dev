## ⚙️ Distributed Text Processing System

**Java · Distributed Systems · AWS/GCP · Lanterna**

A distributed text-processing system designed to divide computational work between multiple workers.

### Architecture

```text
                ┌──────────────┐
                │  Dispatcher  │
                └──────┬───────┘
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
     ┌────────┐   ┌────────┐   ┌────────┐
     │Worker 1│   │Worker 2│   │Worker 3│
     └────────┘   └────────┘   └────────┘
                       │
                       ▼
                ┌──────────────┐
                │    Monitor   │
                └──────────────┘
```

The system searches for identical **N-word phrases across text files**, distributing the workload among multiple workers.

🔗 **Repository:** [Distributed Text Processing System](https://github.com/luisito2477-dev/distributed-text-proccessing-system.git)
